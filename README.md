# Прайс-лист Cheesmart — Инструкция по установке

## Файлы
- `config.php` — настройки (токен, ID прайс-листа, ID организации)
- `api.php` — прокси к API МойСклад
- `index.html` — страница прайс-листа

---

## Шаг 1 — Получить токен МойСклад

МойСклад → Настройки (⚙) → Безопасность → **Токен** → Скопировать.

Вставить в `config.php` в строку:
```php
define('MS_TOKEN', 'сюда_вставить_токен');
```

---

## Шаг 2 — Найти ID прайс-листа

### Способ A: через браузер
Откройте МойСклад → Продажи → Прайс-листы → откройте нужный.
В URL будет: `.../pricelist/XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX`
Это и есть ID.

### Способ B: через API (временно)
Откройте в браузере (подставьте ваш токен):
```
https://api.moysklad.ru/api/remap/1.2/entity/pricelist
```
Заголовок Authorization: Bearer ВАШ_ТОКЕН

Или запустите команду:
```bash
curl -H "Authorization: Bearer ВАШ_ТОКЕН" \
  https://api.moysklad.ru/api/remap/1.2/entity/pricelist
```

Скопировать нужный `id` и вставить в config.php:
```php
define('MS_PRICELIST_ID', 'id-прайс-листа');
```

---

## Шаг 3 — Найти ID организации

МойСклад → Настройки → Организации → откройте вашу организацию.
В URL: `.../organization/XXXXXXXX-...`

```php
define('MS_ORGANIZATION_ID', 'id-организации');
```

---

## Шаг 4 — Загрузить на хостинг

Загрузите все три файла в папку поддомена, например:
```
/public_html/price/   (если поддомен price.cheesmart.ru)
```

Или создайте поддомен в панели хостинга, указав путь к папке.

---

## Шаг 5 — Настроить CORS (если нужно)

В `config.php` поменяйте:
```php
define('ALLOWED_ORIGIN', 'https://price.cheesmart.ru');
```

---

## Проверка

Откройте в браузере:
```
https://price.cheesmart.ru/api.php?action=products
```
Должен вернуться JSON с товарами.

---

## Возможные проблемы

| Ошибка | Решение |
|--------|---------|
| `MS_PRICELIST_ID не задан` | Заполните config.php |
| `cURL error` | Хостинг блокирует исходящие запросы — попросите поддержку разрешить api.moysklad.ru |
| Цены = 0 | Убедитесь, что в прайс-листе заполнены цены |
| 401 Unauthorized | Неверный токен |

---

## Как работает заказ

1. Покупатель заполняет корзину и форму с именем + телефоном
2. `api.php` ищет контрагента в МойСклад по телефону (или создаёт нового)
3. Создаётся «Заказ покупателя» в МойСклад с позициями
4. Покупатель видит номер заказа на экране
